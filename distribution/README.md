# Emerald Arcade

制作者：**POKAZINE**

NexusArkのペルソナと遊ぶ、非公式ファン制作のローカルゲーム集です。
NexusArkの公式製品ではありません。ゲームごとのルールは、アプリの「ルールを読む」から確認できます。

このパッケージはv0.1.0の試用版です。確認環境と既知の制限は、このREADMEと配布元GitHubのリリース説明をご確認ください。

## 必要なもの

- WindowsとNode.js 22.13以降。追加のnpmパッケージのインストールは不要です。
- ペルソナと遊ぶ場合は、NexusArk本体とAPI・MCPの連携設定、利用するモデルのAPI利用環境が必要です。
- ペルソナとの会話にはモデル側の利用料が発生する場合があります。練習ボット・操作練習ではAIのAPIを使いません。

## 起動と停止

### Node.jsが入っているか確認する

Node.jsは、このアプリのローカルサーバーを動かすための実行環境です。NexusArkが動いていても、別途インストールが必要な場合があります。

1. まずPowerShellで `node --version` を実行します。22.13以降（例：`v22.13.0`）が表示されれば、再インストールせず次の起動手順へ進めます。
2. コマンドが見つからない、または古い版の場合は、[Node.js公式ダウンロードページ](https://nodejs.org/en/download)からWindows用のLTS版をインストールします。
3. 新しく開いたPowerShellで `node --version` を確認します。認識されない場合は、PCを再起動するか、Node.jsのインストール設定でPATHへの追加を確認してください。追加のnpmパッケージのインストールは不要です。

### アプリを起動する

1. ZIPを展開します。ZIPの中から直接起動しないでください。
2. 展開したフォルダ内の `Start.bat` をダブルクリックします。
3. ブラウザにゲーム選択画面が開きます。開かない場合は http://127.0.0.1:8040/gameapps/ へアクセスします。
4. 停止は `Stop.bat` から行います。ペルソナの応答待ちが終わってから停止してください。

ブラウザを閉じるだけではサーバーは停止しません。`Start.bat` でNode.jsが見つからないと表示された場合は、上の導入手順を確認してください。

本体と同じ階層に置くと整理しやすくなりますが、必須ではありません。本体のフォルダ名を変更する必要はなく、本体フォルダの中に入れる必要もありません。

ポート8040が使用中なら、PowerShellでこのフォルダを開き、次のように別のポートで起動できます。

```powershell
$env:GAMEAPPS_PORT = '8041'
node --no-warnings launcher.mjs
```

この方法で起動した場合は、同じPowerShellで `node --no-warnings stop.mjs` を実行して停止します。

## 初回の連携

API・MCPの設定は、[連携方法の解説動画（YouTube）](https://youtu.be/-EHe7lOYDls)でも確認できます。NexusArkとEmerald Arcadeの接続設定から、ペルソナがゲームを操作するまでの流れを紹介しています。

ホームの連携ガイドでAPI GatewayのURLと必要なTokenを設定し、相手のルーム一覧を確認します。
次に、ガイドに表示されるEmerald ArcadeのMCP接続情報をNexusArk本体へ登録し、本体の接続テストとツールの有効化・承認を確認してください。
本体の版によって設定画面名が違う場合があります。Emerald Arcadeから本体のファイルを自動編集することはありません。

1. まず「練習ボット」で画面の操作を試せます。この段階では本体への連携は不要です。
2. NexusArkを起動し、APIの接続を確認します。ブラウザで開く本体のURLと、API GatewayのURLは別の場合があります。連携ガイドの入力例を確認してください。
3. MCP登録済みでも「未確認」と出る場合は、NexusArk側で接続テストを行い、Emerald Arcadeの「確認状況を更新」を押します。認証された接続・ツール一覧取得の受信記録を使って確認します。
4. API・MCPの確認後、本体側でツールの有効化・承認を確認し、遊びたいルームを選びます。接続確認だけでは、ペルソナが実際に操作できることまでは保証しません。

遊ぶときは、Emerald Arcadeの盤面とNexusArkの会話画面を並べると便利です。連携案内をホームから隠した後も、右上の設定から開き直せます。

遊ぶ長さ・人数・追加ルールはゲームごとに異なります。開始画面で採用ルールを選び、ルールブックで確認できます。ホームの「AI利用量の目安」は金額の保証ではなく、会話や操作の回数に基づく目安です。

## スマホなどから遊ぶ

初期状態ではPC内だけで使います。同じネットワーク内で使う場合は、共通設定のネットワークで外部接続を有効にし、保存してEmerald Arcadeを再起動してください。
表示されたPC側のURLとEmerald Arcade専用の接続キーを使います。NexusArk用Tokenをスマホへ入力する必要はありません。
インターネットへサーバーを直接公開するための機能ではありません。

## 記録と更新

設定・認証キー・対局記録は、起動時に作られる `data` フォルダへ保存します。このフォルダを他人へ配布しないでください。
更新時はEmerald Arcadeを停止し、既存フォルダをバックアップしてから、新しいプログラムを上書きします。自分の `data` は残してください。
更新版を別フォルダで初期状態から使うこともできます。既存版と同じポートでは同時起動できません。

設定済みのフォルダを丸ごと誰かに渡さず、配布された元のZIPを渡してください。自分の版を更新する際も、旧版のバックアップは動作確認が済むまで保管してください。

## 問題が起きたら

配布元GitHubリポジトリの **Issues → New issue → 不具合の報告** から報告できます。ゲーム名、再現手順、使用モデル、環境を分かる範囲で記入してください。dataフォルダ・DB・ログ全体を投稿する必要はありません。

アプリの版番号・ゲーム名・再現手順・表示されたエラーを控えてください。
ログや画像を公開する際は、Token・接続キー・会話・未公開の手札や真相が含まれていないか確認してください。
このパッケージの収録ファイルとSHA-256は `PACKAGE-MANIFEST.json` で確認できます。

ペルソナが返事だけして着手しない場合は、対局画面の「接続に困ったとき」を開き、本体の稼働・MCP承認・最新状態を確認してください。応答待ちの間に何度も送信せず、画面の復旧案内に従ってください。
モデルによってはルールや秘密情報に関する指示を守れない場合があります。未公開の手札や真相を含む会話を、そのまま共有しないようにしてください。
