# 素材・依存の記録方針

新しい素材や依存を追加した時点で、この文書に出典と利用条件を残す。公開直前にまとめて記憶から推測しない。

現時点のpublicはHTML・CSS・JavaScriptで構成され、画像・音声・フォントの外部ファイルは含まれていない。これだけで権利確認が完了したことを意味しない。ゲーム名・ルール説明・コード・デザインの公開可否は公開前の確認対象とする。

| 対象 | 現在の構成 | 公開前の確認 |
| --- | --- | --- |
| ゲームのイラスト・アイコン | public内のCSS／SVG文字列／HTMLで描画 | 参照資料と表現を確認。出典が必要な素材を追加したら個別に記録 |
| 効果音 | public内のJavaScriptによる合成 | 収録音源を追加したら音源の出典と利用条件を記録 |
| フォント | 利用端末のフォントをCSSで指定 | フォントファイルを同梱する場合は再配布条件を確認 |
| 実行環境 | Node.jsの組み込み機能。追加npm依存なし | 依存導入時はライセンス・配布方法・必要なnoticeを確認 |
| Emerald Arcadeのコード全体 | LICENSE.mdに独自の個人利用条件を設定 | 個人の非商用利用・手元での改造可、再配布・商用不可。GitHub規約に必要なFork等は例外。第三者の権利確認とは別に扱う |

今後の記録項目：対象ファイル／素材名、作者・提供元、元URL、取得日、ライセンスの名称と確認先、改変の有無、再配布・クレジット等の条件、同梱するnoticeの場所。

この文書自体は開発用。必要なクレジットは配布用文書へ転記し、release.config.jsonのdocumentsかoptionalDocumentsで明示的に収録する。

## しるしの四重奏

盤面・16種類の駒・ホーム／記録用イラストは独自SVGとCSS、共有画像はCanvasで作成。高低差の代わりに無地／しま模様を使用します。配置と受け渡しの短い効果音はWeb Audioによる合成音で、外部の画像・音声・ライブラリは追加していません。

## 九旗のかけひき

9旗・部隊札・戦術札・ホーム／記録用イラストは独自HTML/CSSとSVG、結果画像はCanvasで描画。操作音はWeb Audioで合成。外部画像・音源・フォント・ライブラリは追加していません。ルールの調査資料とApp独自の扱いはNINEFLAGS.mdへ記載。
